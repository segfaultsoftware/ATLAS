# Project Instructions

- Use neutral, descriptive language. Avoid adding subjective opinions or evaluative commentary unless the user explicitly asks for interpretation.
- Use FactoryBot for reusable spec fixtures instead of ad hoc helper builders.
- Call FactoryBot explicitly, such as `FactoryBot.build` and `FactoryBot.create`, instead of using FactoryBot syntax methods like `build(...)` or `create(...)`.
