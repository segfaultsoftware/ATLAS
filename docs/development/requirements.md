She names the game "Gina's Saturday Game" and names the starting ship "The Hoover". Submitting this form takes her to the GM Screen page. She ignores adding players for now and wants to go configure The Hoover. On the GM Screen, she sees a list of Player Ships, including The Hoover. She clicks into The Hoover. On The Hoover is a diagram of the spaceship. The spaceship is arranged like a skyscraper on the left side of the page with each floor (Deck) having a label and function. The Default Ship is there which includes all Decks to be an effective spaceship. She notices the randomly generated wear and tear of each Deck. She doesn't like the Default Ship, so she finds the header Ship Class with the dropdown below it. The current, default selection is "Mira Fox 18.7.1", which is the default Ship Class when generating a new ship. The dropdown contains many Ship Classes and the dropdown has an "SRD" link next to it. Gina clicks the SRD link and a new tab is opened linking to the hosted SRD on Ship Classes. She reads the description of the current Ship Classes and switches back to her previous tab and chooses "Mira Clydesdale 16.1". A dialog pops up confirming Gina wants to regenerate the ship. She confirms, and the Fox is now replaced by the Clydesdale.

## SRD Ruleset Requirements

The ATLAS ruleset should be documented as the ATLAS SRD and written for new-to-RPG players. Rules text should also be structured enough for implementation in the ATLAS app.

Core check requirements:

- Skill ratings determine the number of `d6` skill dice rolled.
- A character rolls at least 1 skill die when attempting a check.
- Skill dice results of `1-2` count as 0 successes.
- Skill dice results of `3-6` count as 1 success.
- The GM or rules system sets a target number of successes.
- Every check includes one Luck die, which is a `d10`.
- A check is a critical success when counted skill dice successes are equal to or greater than the target and the Luck die result is `10`.
- A check is a success when counted skill dice successes are equal to or greater than the target and the Luck die result is not `10`.
- A check is a success when counted skill dice successes are lower than the target and the Luck die result is `10`.
- A check is a failure when counted skill dice successes are lower than the target and the Luck die result is not `10`.
- Failure means the action ends in an unfavorable outcome.
- Success means the action ends in a favorable outcome, but with a catch.
- Critical success means the action ends perfectly.

SRD content requirements:

- Explain tabletop roleplaying concepts in plain language.
- Define the roles of GM and players.
- Emphasize ships, gear, supplies, and possessions as central parts of play.
- Support theatre-of-the-mind play.
- Support high-risk violence and lasting consequences.
- Support random tables and generators for world, map, ship, faction, job, and hazard creation.
- Provide rules in stable, structured sections suitable for linking from the app.
