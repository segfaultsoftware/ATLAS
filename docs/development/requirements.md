# Requirements

## General Workflow

Gina would like to run a game of ATLAS. She goes to the ATLAS webpage and creates an account. From in the app, she finds the "Create a New Game" button and clicks it. She names the game "Gina's Saturday Game" and names the starting ship "The Hoover". Submitting this form takes her to the GM Screen page. She ignores adding players for now and wants to go configure The Hoover. On the GM Screen, she sees a list of Player Ships, including The Hoover. She clicks into The Hoover. On The Hoover is a diagram of the spaceship. The spaceship is arranged like a skyscraper on the left side of the page with each floor (Deck) having a label and function. The Default Ship is there which includes all Decks to be an effective spaceship. She notices the randomly generated wear and tear of each Deck. She doesn't like the Default Ship, so she finds the header Ship Class with the dropdown below it. The current, default selection is "Mira Fox 18.7.1", which is the default Ship Class when generating a new ship. The dropdown contains many Ship Classes and the dropdown has an "SRD" link next to it. Gina clicks the SRD link and a new tab is opened linking to the hosted SRD on Ship Classes. She reads the description of the current Ship Classes and switches back to her previous tab and chooses "Mira Clydesdale 16.1". A dialog pops up confirming Gina wants to regenerate the ship. She confirms, and the Fox is now replaced by the Clydesdale.
